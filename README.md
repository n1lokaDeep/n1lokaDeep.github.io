# n1lokaDeep — портфолио

Страница с услугами и примерами работ: **https://n1lokadeep.github.io/**

## Что здесь

- `index.html` — сама страница
- `style.css` — оформление

Публикуется автоматически через GitHub Pages из ветки `main`, корень репозитория.
Никаких сборщиков и зависимостей: чистый HTML и CSS, страница открывается сразу.

## Стек

Ручная вёрстка, адаптивная сетка на CSS Grid, тёмная тема, один акцентный цвет.
Внешних скриптов нет — только несколько строк JavaScript для года в подвале.
